# Feloral Frontend — Luxury AI-ready Starter

فرانت‌اند اولیه فلورال با Next.js + TypeScript + Tailwind.

## اجرا

```bash
npm install
npm run dev
```

سایت روی این آدرس اجرا می‌شود:

```txt
http://localhost:3001
```

## اتصال به بک‌اند

فایل `.env.local` بسازید:

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:3000
```

## ویژگی‌های آماده‌شده

- صفحه اصلی لوکس و RTL
- هدر، هیرو، دسته‌بندی، محصولات، بنر رایحه، مجله و فوتر
- ساختار API client برای اتصال به بک‌اند
- ساختار آماده برای:
  - تولید اطلاعات محصول با هوش مصنوعی
  - مقایسه قیمت با سایت‌های دیگر
  - تست رژ لب با عکس یا دوربین
  - ویدیوهای جذاب برای نت‌های بویایی
  - صفحات محصول، فروشگاه، سبد خرید و ادمین
